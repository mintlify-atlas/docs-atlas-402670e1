The configuration endpoints expose the global key/value settings stored in the DBImport configuration database. These keys control every subsystem — Airflow integration, HDFS paths, Hive behaviour, import/export session limits, Kafka event streaming, REST server settings, and more. JDBC driver registrations (classpath and driver class per database type) are managed separately via the JDBC driver endpoints. All endpoints require a valid Bearer token.

<Note>
  The keys `restserver_admin_user`, `restserver_authentication_method`, and `restserver_token_ttl` are only visible to and editable by the configured admin user. The `restserver_secret_key` is never exposed via the API.
</Note>

---

## GET /config/getJDBCdrivers

Returns the full list of JDBC driver registrations. Each entry maps a `databaseType` / `version` combination to a driver class name and classpath. These entries are used by `POST /connection/generateJDBCconnectionString` to validate database type and version combinations.

**Authentication:** Bearer token required

### Response Fields

Returns an array of JDBC driver objects:

<ResponseField name="databaseType" type="string" required>
  Database platform label (e.g. `Oracle`, `MySQL`, `SQL Server`, `PostgreSQL`, `Snowflake`, `DB2 UDB`, `DB2 AS400`).
</ResponseField>

<ResponseField name="version" type="string" required>
  Driver version label (e.g. `default`, `jTDS`).
</ResponseField>

<ResponseField name="driver" type="string" required>
  Fully-qualified Java driver class name (e.g. `oracle.jdbc.driver.OracleDriver`).
</ResponseField>

<ResponseField name="classpath" type="string" required>
  Filesystem path to the JDBC driver JAR file.
</ResponseField>

```json title="Example response"
[
  {
    "databaseType": "Oracle",
    "version": "default",
    "driver": "oracle.jdbc.driver.OracleDriver",
    "classpath": "/opt/drivers/ojdbc8.jar"
  },
  {
    "databaseType": "SQL Server",
    "version": "default",
    "driver": "com.microsoft.sqlserver.jdbc.SQLServerDriver",
    "classpath": "/opt/drivers/mssql-jdbc.jar"
  }
]
```

## POST /config/updateJDBCdriver

Updates the driver class name and classpath for an existing `databaseType` / `version` entry. The combination must already exist in the database — this endpoint updates only; it does not create new driver records.

**Authentication:** Bearer token required

### Request Body

<ParamField body="databaseType" type="string" required>
  Database platform identifier. Must match an existing entry.
</ParamField>

<ParamField body="version" type="string" required>
  Driver version label. Must match an existing entry alongside `databaseType`.
</ParamField>

<ParamField body="driver" type="string" required>
  Updated Java driver class name.
</ParamField>

<ParamField body="classpath" type="string" required>
  Updated path to the JDBC driver JAR.
</ParamField>

### Response

Returns `"ok"` with HTTP `200` on success. Returns HTTP `400` with an error message if the `databaseType`/`version` combination is not a supported entry.

## POST /config/updateConfig

Updates one or more global configuration keys. Only the keys explicitly set in the request body (non-null values) are written to the database; all other keys remain unchanged.

**Authentication:** Bearer token required

<Warning>
  Updating `restserver_admin_user`, `restserver_authentication_method`, or `restserver_token_ttl` is restricted to the admin user. Attempting to update these keys as a non-admin returns HTTP `403`.
</Warning>

### Request Body

A partial `configuration` object. Include only the keys you want to change. Keys not present in the request body are left unchanged.

```json title="Example: update Airflow URL and session limits"
{
  "airflow_url": "https://airflow.internal.example.com",
  "import_default_sessions": 4,
  "import_max_sessions": 10
}
```

### Validation Rules

- `airflow_major_version` must be `1` or `2`
- `restserver_authentication_method` must be `"local"` or `"pam"`
- String values cannot be set to empty strings

### Response

Returns `"ok"` with HTTP `200` on success. Returns HTTP `400` on invalid values, or HTTP `403` when a non-admin attempts to change restricted keys.
