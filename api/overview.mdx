The DBImport REST API exposes the full power of the platform over HTTP, enabling you to automate connection management, configure import and export tables, generate Airflow DAGs, and adjust global settings without touching the database directly. The server is built with [FastAPI](https://fastapi.tiangolo.com/) and served through Gunicorn with Uvicorn workers, making it suitable for both interactive tooling and CI/CD pipelines.

## Server startup

The REST server is a standalone process separate from the main DBImport daemon. Start it with the `restServer` executable found in the `bin/` directory.

```bash
# Start as a background daemon
./restServer start

# Start in the foreground (useful for debugging)
./restServer noDaemon

# Stop the server
./restServer stop

# Restart the server
./restServer restart

# Check whether the server is running
./restServer status
```

Each action accepts the following options:

| Option | Short | Description |
|---|---|---|
| `--help` | `-h` | Print usage information and exit |
| `--debug` | `-v` | Enable verbose debug-level logging |
| `--version` | `-V` | Print the DBImport version and exit |

<Note>
  `./mainServer` manages the main DBImport processing daemon, not the REST server. Use `./restServer` exclusively for the API process.
</Note>

The server binds to the address and port configured in the `[Server]` section of the DBImport configuration file (`restServer_address`, `restServer_port`, `restServer_workers`, `restServer_keyfile`, `restServer_certfile`).

## Base URL

All API requests are made to the host and port where the server is running:

```text
https://<host>:<port>
```

For example, if the server runs on `dbimport-server` at port `8080`:

```text
https://dbimport-server:8080
```

## Verifying the server

The `/status` endpoint is unauthenticated and can be used to confirm that the server is reachable and to inspect the running version:

```bash
curl https://dbimport-server:8080/status
```

```json
{
  "status": "ok",
  "version": "1.00.006"
}
```

## Content type

All request bodies must be sent as JSON and all responses are returned as JSON. Set the `Content-Type` header accordingly on write operations:

```text
Content-Type: application/json
```

## Authentication

The API uses the **OAuth2 password flow**. Send your credentials to `/oauth2/access_token` to receive a short-lived JWT Bearer token, then include that token in the `Authorization` header of every subsequent request.

```text
Authorization: Bearer <token>
```

The `/status` and `/oauth2/access_token` endpoints are the only routes that do not require authentication. All other endpoints will return `401 Unauthorized` if a valid token is not present. See the [Authentication guide](/api/authentication) for the full flow, token TTL configuration, and supported authentication back-ends.

## Server configuration

The REST server reads several keys from the `configuration` table in the DBImport database at startup:

| Configuration key | Description |
|---|---|
| `restserver_admin_user` | Username of the built-in administrator account |
| `restserver_authentication_method` | Authentication back-end: `local` or `pam` |
| `restserver_token_ttl` | Token lifetime in minutes |
| `restserver_secret_key` | Secret used to sign JWT tokens — keep this value private |

## Endpoint summary

The table below lists every route grouped by resource area. The `GET /status` and `POST /oauth2/access_token` routes are public; all others require a Bearer token.

### General

| Method | Path | Description |
|---|---|---|
| `GET` | `/status` | Returns server status and version. No auth required. |
| `POST` | `/oauth2/access_token` | Obtain a JWT access token. No auth required. |

### Connections — `/connection`

| Method | Path | Description |
|---|---|---|
| `GET` | `/connection` | List all connections |
| `POST` | `/connection` | Create or update a connection |
| `GET` | `/connection/{connection}` | Get details for a specific connection |
| `DELETE` | `/connection/{connection}` | Delete a connection |
| `POST` | `/connection/search` | Search connections by field values |
| `GET` | `/connection/testConnection/{connection}` | Test JDBC connectivity |
| `POST` | `/connection/encryptCredentials` | Encrypt and store JDBC credentials |
| `POST` | `/connection/generateJDBCconnectionString` | Generate a JDBC URL for a given database type |

### Imports — `/import`

| Method | Path | Description |
|---|---|---|
| `GET` | `/import/db` | List all import databases |
| `POST` | `/import/search` | Search import table definitions |
| `POST` | `/import/discover/search` | Discover source tables available for import |
| `POST` | `/import/discover/add` | Add discovered tables as import definitions |
| `GET` | `/import/table/{connection}` | List import tables for a connection |
| `GET` | `/import/table/{database}` | List import tables in a Hive database |
| `GET` | `/import/table/{database}/{table}` | Get full import table configuration |
| `POST` | `/import/table/{database}/{table}` | Create or update an import table |
| `DELETE` | `/import/table/{database}/{table}` | Delete an import table definition |
| `POST` | `/import/table/{database}/{table}/repair` | Repair an import table |
| `POST` | `/import/table/{database}/{table}/reset` | Reset import state for a table |
| `POST` | `/import/table` | Bulk update import tables |
| `DELETE` | `/import/table` | Bulk delete import tables |

### Exports — `/export`

| Method | Path | Description |
|---|---|---|
| `GET` | `/export/connection` | List connections that have export definitions |
| `POST` | `/export/search` | Search export table definitions |
| `POST` | `/export/discover/search` | Discover Hive tables available for export |
| `POST` | `/export/discover/add` | Add discovered tables as export definitions |
| `GET` | `/export/table/{connection}` | List export tables on a connection |
| `GET` | `/export/table/{connection}/{schema}` | List export tables for a connection and schema |
| `GET` | `/export/table/{connection}/{schema}/{table}` | Get full export table configuration |
| `POST` | `/export/table/{connection}/{schema}/{table}` | Create or update an export table |
| `DELETE` | `/export/table/{connection}/{schema}/{table}` | Delete an export table definition |
| `POST` | `/export/table/{connection}/{schema}/{table}/repair` | Repair an export table |
| `POST` | `/export/table/{connection}/{schema}/{table}/reset` | Reset export state for a table |
| `POST` | `/export/table` | Bulk update export tables |
| `DELETE` | `/export/table` | Bulk delete export tables |

## Interactive API explorer

FastAPI automatically generates an OpenAPI schema for the DBImport REST server. Once your server is running, visit the built-in Swagger UI at:

```text
https://<host>:<port>/docs
```

Or use the alternative ReDoc interface at:

```text
https://<host>:<port>/redoc
```

These pages let you explore every endpoint, inspect request and response schemas, and execute calls directly from your browser.
