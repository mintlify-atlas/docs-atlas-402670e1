DBImport is an ELT ingestion tool that handles the full lifecycle of moving data between relational databases (Oracle, MSSQL, MySQL, DB2, PostgreSQL, Snowflake, and more) and your Hadoop/Hive data lakehouse. It automates table discovery, schema change propagation, incremental ingestion, Airflow DAG generation, and data governance via Apache Atlas — so you spend time on analytics, not pipelines.

## Why DBImport?

When source systems change their table schemas — renaming columns, adding fields, or altering types — traditional Sqoop scripts break silently. DBImport detects those changes automatically and propagates them to Hive, turning a production incident into a log entry.

## How It Works

<Steps>
  <Step title="Connect to a source database">
    Add a JDBC connection to your source system — Oracle, MSSQL, MySQL, DB2, PostgreSQL, Snowflake, or AWS S3. Credentials are encrypted with an RSA keypair stored on the server.
  </Step>
  <Step title="Discover tables automatically">
    Run `./manage --addImportTable -a <connection> -h <hive_db>` to scan the source and register all matching tables in the configuration database. Filters by schema or table name pattern.
  </Step>
  <Step title="Generate an Airflow DAG">
    Insert a row into `airflow_import_dags` with a wildcard filter (e.g., `dbimport.*`), then run `./manage --airflowGenerate` to produce a fully-wired Airflow DAG file.
  </Step>
  <Step title="Run imports on a schedule">
    The generated DAG runs on your configured interval. DBImport handles schema changes, row-count validation, history audit tables, and statistics — automatically, every run.
  </Step>
</Steps>

## Supported Source Systems

DBImport connects to any JDBC-accessible database. Supported types include:

| Database | Import | Export | CDC |
|----------|--------|--------|-----|
| Oracle | ✓ | ✓ | Flashback Query |
| Microsoft SQL Server | ✓ | ✓ | Change Tracking |
| MySQL / MariaDB | ✓ | ✓ | — |
| PostgreSQL | ✓ | ✓ | — |
| DB2 UDB / AS400 | ✓ | ✓ | — |
| Snowflake | ✓ | ✓ | — |
| AWS S3 | — | ✓ | — |
| MongoDB | ✓ | — | — |
| Progress / OpenEdge | ✓ | — | — |

<Note>
  DBImport requires Python 3.6+, a MariaDB/MySQL configuration database, Kerberos authentication, and Hive with binary transport mode. See [Requirements](/requirements) for the full list.
</Note>
